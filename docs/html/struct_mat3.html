Opis szczegółowy

Struktura Mat3 reprezentująca macierz 3x3.

Macierz 3x3 jest wykorzystywana do transformacji 2D obiektów w przestrzeni, takich jak:

  • Przesunięcie
  • Obrót
  • Skalowanie
