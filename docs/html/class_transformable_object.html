Opis szczegółowy

Klasa TransformableObject reprezentuje obiekt 2D, który można poddać transformacjom.

Klasa ta przechowuje informacje o pozycji, rotacji i skali obiektów oraz udostępnia metody do ich modyfikacji. Można ją stosować do wszelkiego rodzaju obiektów, które wymagają możliwości przesunięcia, obrotu i skalowania, takich jak figury geometryczne w grze lub aplikacji graficznej.
