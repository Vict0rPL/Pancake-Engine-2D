◆ Update()

void Game::Update ( float deltaTime)
overridevirtual

Aktualizuje stan sceny. Wywoływane w każdej klatce.

Aktualizuje logikę gry.

Parametry
deltaTimeCzas (w sekundach) od ostatniej klatki.

Ta funkcja jest wywoływana w każdej klatce, aby zaktualizować stan gry, logikę gry, np. ruch gracza, interakcje z obiektami, czy sprawdzanie warunków zwycięstwa.

Parametry
deltaTimeCzas, który upłynął od ostatniej aktualizacji. Może być używany do płynnego animowania obiektów.
