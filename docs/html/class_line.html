Opis szczegółowy

Klasa Line reprezentująca linię w przestrzeni 2D.

Ta klasa umożliwia tworzenie obiektów linii, ich rysowanie, transformowanie (przesunięcie, rotację, skalowanie) oraz konwertowanie do formatu JSON.
